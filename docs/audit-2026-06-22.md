## Fix now

### 1. Webhook secret uses `.includes()` substring match
- **File:** `api/admin-enquiries.js:607`
- **Category:** Security
- **Detail:** `Object.values(req.headers).some(v => String(v).includes(secret))` — if the secret is short, it could match a substring of an unrelated header value. Should do exact Bearer token comparison with `crypto.timingSafeEqual()`.

### 2. Cookie auth uses `===` instead of timing-safe compare
- **File:** `api/_auth.js:48`
- **Category:** Security
- **Detail:** `userToken(user) === token` is vulnerable to timing attacks in theory. Switch to `crypto.timingSafeEqual()` for the HMAC comparison.

### 3. Halaxy URL inserted into href unescaped
- **File:** `js/admin-ui.js:349`
- **Category:** XSS
- **Detail:** The Halaxy URL input value is interpolated directly into an `<a href="...">` without `escHtml()`. A `javascript:` protocol URL could execute code. Both users are trusted admins so risk is low, but easy to fix.

### 4. Verify `CRON_SECRET` is set in Vercel
- **Category:** Infra
- **Detail:** If `CRON_SECRET` is unset, the reminder cron (`GET /api/admin-enquiries?reminder_cron=1`) falls back to the spoofable `x-vercel-cron` header. Check Vercel dashboard → Production env vars. If missing, set it and redeploy.

### 5. 12/12 serverless functions — zero headroom
- **Category:** Capacity
- **Detail:** Hobby plan max is 12. Current functions: `admin`, `admin-login`, `admin-enquiries`, `admin-intake`, `admin-tasks`, `calendar-pending`, `clients`, `contact`, `google-auth`, `google-callback`, `session`, `sessions`. Next feature must consolidate into an existing handler (query param routing) or hit the wall.

## Improvements

### 1. O(n^2) client lookups in schedule renderer
- **Category:** Performance
- **Detail:** Multiple `.find()` calls inside loops searching `_pipelineData.clients` by `halaxy_id`. Pre-compute a `halaxyIdMap` lookup. Not a problem at current scale (~30 clients) but will degrade.

### 2. Activity log inserts silently swallowed
- **File:** `api/admin-enquiries.js:1957`
- **Category:** Resilience
- **Detail:** `catch (_) {}` hides audit trail failures. Change to `catch (e) { console.warn(...) }` so failures are at least logged.

### 3. Pull-to-refresh listeners not cleaned up
- **Category:** Resilience (mobile)
- **Detail:** Touch handlers added to `.app-content` accumulate on navigation. Minor memory leak on mobile after repeated view switches.

### 4. No stale-tab detection
- **Category:** UX
- **Detail:** A tab left open across a deploy keeps running old JS until manually reloaded. A periodic version-check fetch (compare commit SHA) with a "New version available — reload" banner would fix this. Parked in TODO.md.

### 5. Inconsistent null handling patterns
- **Category:** Code quality
- **Detail:** Mix of `|| null`, `?? null`, and bare falsy checks across the codebase. Not buggy but inconsistent.

### 6. CSS consolidation branch still unmerged
- **Branch:** `refactor/css-consolidation`
- **Category:** Tech debt
- **Detail:** Foundation + 3 slices (detail panel, sidebar, settings) complete and verified pixel-identical. Remaining: app-shell slice (`.app-shell`/`.app-main`/`.view-content`/`.app-topbar`, ~26 `!important` decls) + ~3 mobile settings stragglers.

### 7. `admin-ui.js` is ~10k lines
- **Category:** Code quality
- **Detail:** Not urgent since it's static-served (no bundler), but could eventually split into modules (navigation, rendering, data, modals) if the file keeps growing.

### 8. `RESEND_DOMAIN_VERIFIED` not in CLAUDE.md env table
- **File:** `api/contact.js`
- **Category:** Docs
- **Detail:** This env var controls the "from" address in contact form emails but isn't listed in the Key Env Vars table.

## False positives (investigated and dismissed)

- **"DST bug in timezone hardcoding"** — Brisbane/QLD is UTC+10 year-round (no daylight saving). The hardcoded `+10:00` is correct.
- **"Missing light mode"** — the app is designed dark-only, intentional.
- **"Session ownership validation"** — only 2 trusted admin users (Julian + Cheree), not multi-tenant.
- **"XSS in email templates"** — email clients don't execute JavaScript.
- **"Google token race condition"** — requires two admins to click Reconnect at the exact same millisecond. Impossible with 2 users.
